Tracing reminders

  • Without break, execution falls through into the next case's statements.
  • A return inside a case leaves the whole method immediately.
  • default runs only when no case matches, or when an earlier case falls into it.
  • In Java, % keeps the sign of the left operand: -3 % 4 is -3.
